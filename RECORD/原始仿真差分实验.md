# RECORD 原始仿真与差分坐标报告

在本目录运行 `python record_dp_experiment.py --trials 3 --seconds 60 --seed 20261117`。使用仓库 requirements.txt 中的依赖及 Shapely 2。输出在 `my_simulations/record-dp/`。

脚本调用上游仿真入口，使用合成终端、100 km 接收点间距、三个接收点、历史 TLE、弱事件和带噪预测波束。新增回调读取联合候选多边形，保留上游的事件生成和位置估计。NumPy 2 兼容修复将已移除的别名改为 np.prod 和 np.nan。

对有效候选区，比较候选区内均匀先验、精确坐标和已知噪声模型下的扰动坐标。每个有效场景独立抽样 64 套报告序列，单次预算为 0.2 km⁻¹，统计 1、4、16、64 次报告后的投影平面定位误差。差分组使用数值近似计算后验均值。RECORD 候选区在三组中固定，报告次数变化只反映坐标披露的累积效应。无效场景计入结果文件，定位误差按有有效候选区的场景统计。默认配置用于流程验证，样本规模仍需扩大。

本次 3 个合成场景均得到包含终端的联合候选区，面积约为 709947、336808 和 442761 km²。仅用候选区的平均估计误差为 223.49 km。差分报告的平均误差随上报次数由 9.92 km（1 次）降至 1.17 km（64 次），64 次时 1 km 内比例为 44.27%。精确报告因直接提供模拟真值而为 0 km。每个场景的 64 套上报噪声属于同一候选区内的重复，不能视为额外的独立轨道场景。

## 原始基线重跑

原始入口 `simulations_attackerTypes_fibo.py` 使用相同的 60 秒默认配置运行了 10 个有效场景，NumPy 随机种子为 20261117。基于公开波束工件，三个接收点的联合候选面积中位数为 **399056.68 km²**。对应的作者公开模型存档包含 86 行，中位数为 **467882.56 km²**。本轮中位数比存档低约 14.7%，两者使用的样本数量与场景不同，不能据此判定存在实现偏差。原始基线 CSV 位于 `my_simulations/duration_and_type/`。

重跑原始入口前需创建输出目录。入口会向同名 CSV 追加结果，应使用空输出目录或先归档旧结果。

```sh
mkdir -p my_simulations/duration_and_type
python -c 'import runpy, numpy as np; np.random.seed(20261117); runpy.run_path("simulations_attackerTypes_fibo.py", run_name="__main__")'
```
